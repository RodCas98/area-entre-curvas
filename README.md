# Área entre curvas · Cálculo II

Página web interactiva para aprender a calcular el área entre curvas: teoría (integración en x y en y, curvas que se cruzan, frontera que cambia), método paso a paso, 12 ejemplos resueltos (polinómicos, trigonométricos, compuestos y racionales), un laboratorio para graficar y calcular áreas propias, y ejercicios con solución.

Sitio estático (HTML + CSS + JS, sin dependencias de compilación). Las fórmulas usan KaTeX desde CDN.

Para verlo localmente basta abrir `index.html` o servir la carpeta con cualquier servidor estático.
